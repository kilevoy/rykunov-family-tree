# Родословная: первый сценарий (тестовая версия)

Статическое приложение без сборки. Запуск: `python3 -m http.server 8765` в этой папке, затем http://127.0.0.1:8765/index.html.
Данные тестовые и хранятся только в браузере (localStorage). Реальные данные семьи сюда не вносить: репозиторий публичный. Рабочая версия — Next.js + Supabase по `replica/architecture.md`.
Тесты логики: `node --test tests/data.test.mjs`.
