# Ошибки (replica-test)

Билд на момент проверки: 4ba8c67. Браузер: Chromium 141 (headless), 1440 и 390 px. Тесты: `app/tests/regression.test.mjs`, `e2e/run.mjs`.
Слой данных пока фейковый (localStorage), поэтому ошибки BUG-001 и BUG-007 относятся к нему; с Supabase вместо этого действуют версии записей и RLS.

### BUG-001: две вкладки затирают данные друг друга
- Severity: S1
- Flow / case: F01 / F01-E8, F01-E8b
- Screen: S01
- Steps
  1. Открыть приложение в двух вкладках.
  2. Во вкладке A добавить человека.
  3. Во вкладке B (не обновляя её) добавить другого человека.
- Expected: в обеих вкладках оба человека; правка устаревшей записи даёт сообщение о конфликте.
- Actual: вторая запись целиком перезаписывает хранилище, первый человек пропадает; проверка версии не срабатывает, потому что вкладка держит устаревшую копию.
- Evidence: тесты F01-E8, F01-E8b
- Suspected cause: `ensure()` читает хранилище один раз и кэширует.
- Status: fixed (см. ниже)
