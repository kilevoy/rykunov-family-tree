# Родословная Рыкуновых

Закрытый семейный проект для совместного сбора родословной. Не публиковать без согласия семьи.

## Стартовые карточки

### Ольга Пимовна Рыкунова
- Связь с Андреем: бабушка владельца проекта.
- Место жительства: село Алдаркино, Бузулукский район, Оренбургская область.
- Муж: Андрей Иванович Рыкунов.
- Дети: пятеро; имена и даты рождения пока не внесены.
- Награда: медаль «Материнство» II степени, 1954 год.
- Даты рождения и смерти: не установлены.
- Основание: семейные сведения; запись о награждении обнаружена в энциклопедии Бузулукского района и требует сверки с первичными документами.

### Андрей Иванович Рыкунов
- Связь с Ольгой: муж.
- Место жительства семьи: село Алдаркино, Бузулукский район, Оренбургская область.
- Сведения о военной службе: инвалид Великой Отечественной войны (по семейным сведениям).
- Даты рождения и смерти, место рождения, воинская часть, награды: пока не установлены.

## Черновое родственное дерево

```text
Ольга Пимовна Рыкунова ── Андрей Иванович Рыкунов
                         │
                         └── пятеро детей (имена и даты уточняются)
```

## Как добавлять сведения

- Отделять подтверждённые документы от семейных воспоминаний и гипотез.
- Для каждого факта записывать источник, дату и автора/держателя документа.
- Не угадывать даты, отчества, места службы и родственные связи.
- Перед добавлением сканов документов убирать номера и данные живых людей, которые не нужны для дерева.
