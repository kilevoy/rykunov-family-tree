# Родословная Рыкуновых

Семейное древо, собираемое по семейным сведениям и открытым источникам. Неуточнённые факты и расхождения отмечаются отдельно.

**Визуальное древо:** https://kilevoy.github.io/rykunov-family-tree/

## Первое поколение

### Ольга Пименовна Рыкунова
- 20.08.1913 — 07.04.1999.
- Жила в селе Алдаркино, Бузулукский район, Оренбургская область.
- Муж — Андрей Иванович Рыкунов.
- Награждена медалью «Материнство» II степени в 1954 году.

### Андрей Иванович Рыкунов
- Муж Ольги Пименовны.
- По семейным сведениям — инвалид Великой Отечественной войны.
- 15.03.1920 — 25.09.1982.

### Расхождение для проверки

Семейный список содержит шесть имён. В найденной записи о награждении Ольги Пименовны в 1954 году указано пять детей. Не делаем выводов о причине расхождения, пока не сверим документы и семейные сведения.

## Принципы ведения дерева

- Отделять документально подтверждённое от семейных воспоминаний и гипотез.
- Для каждого факта записывать источник и степень уверенности.
- Не угадывать даты, отчества, места службы и родственные связи.
- Перед добавлением сканов документов закрывать номера и сведения живых людей, которые не нужны для дерева.
