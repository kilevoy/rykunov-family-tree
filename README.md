# Родословная Рыкуновых

Семейное древо, собираемое по семейным сведениям и открытым источникам. Неуточнённые факты и расхождения отмечаются отдельно.

**Визуальное древо:** https://kilevoy.github.io/rykunov-family-tree/

## Первое поколение

### Ольга Пименовна Рыкунова
- 20.08.1913 — 07.04.1999.
- Жила в селе Алдаркино, Бузулукский район, Оренбургская область.
- Муж — Андрей Иванович Рыкунов.
- Награждена медалью «Материнство» II степени в 1954 году.

### Андрей Иванович Рыкунов
- Муж Ольги Пименовны.
- По семейным сведениям — инвалид Великой Отечественной войны.
- 15.03.1920 — 25.09.1982.

### Расхождение для проверки

Семейный список содержит шесть имён. В найденной записи о награждении Ольги Пименовны в 1954 году указано пять детей. Не делаем выводов о причине расхождения, пока не сверим документы и семейные сведения.

## Семья Аткаевых и Чичаевых — родители Ольги Пименовны

По семейному подтверждению Ольга Пименовна Рыкунова (урождённая Аткаева) — дочь Пимона Андреевича Аткаева и Евдокии Ивановны. В ранее найденной записи метрической книги села Колок за 1913 год также указаны Пимон Андреев Аткаев, законная жена Евдокия Иванова и дочь Ольга.

- **Пимон Андреевич Аткаев** — отец Ольги; даты жизни ещё устанавливаются.
- **Евдокия Ивановна Аткаева**, предположительно **урождённая Чичаева** — мать Ольги. Девичья фамилия известна **по семейным сведениям, архивно не подтверждена**. Для подтверждения нужна запись о венчании или другой первичный источник.
- **Ольга Пименовна Рыкунова (урождённая Аткаева)** — семейная дата рождения 20.08.1913, умерла 07.04.1999.

**Расхождение дат:** в ранее найденной метрике Ольга родилась 09.07.1913 по старому стилю (22.07.1913 по новому) и крещена 10.07.1913 по старому стилю. С семейной датой рождения 20.08.1913 это не совпадает. Архивная запись требует повторной сверки, независимая идентификация — дополнительных документов. Источник: ОГА Оренбургской области, ф. 389, оп. 2, д. 317, скан 23 — [Яндекс Архивы](https://yandex.ru/archive/catalog/fc63a769-c6f4-40cd-b063-a8d6b3716f5d/23).

**Отдельная ранняя ветвь:** Яков Нестерович Аткаев, его жена Елена Яковлевна и сын Ефим, упомянутые в материалах за 1853 год, не объединяются с линией Пимона Андреевича без документов, доказывающих родство.

## Принципы ведения дерева

- Отделять документально подтверждённое от семейных воспоминаний и гипотез.
- Для каждого факта записывать источник и степень уверенности.
- Не угадывать даты, отчества, места службы и родственные связи.
- Перед добавлением сканов документов закрывать номера и сведения живых людей, которые не нужны для дерева.
